# 0009: 밸런스에 맞는 플레이 성과로 AI를 평가한다

- 상태: Accepted
- 결정일: 2026-10-09
- 대체: [0001](0001-full-clear-first.md)

## 배경

사용자는 현재 게임 밸런스가 완주 가능한 밸런스가 아니라고 설명했다. 따라서 현재 밸런스에서 높은 full-clear 확률을 필수 승인 기준으로 삼으면 정책 개선을 구별할 수 없고, 잘못된 목표 때문에 개발을 계속 미완료로 판단하게 된다. 이 설명은 개발 전제이며 완주 불가능성을 수학적으로 증명한 결과는 아니다.

## 결정

- 목표는 주어진 규칙에서 강하게 플레이하는 AI와 변경 후 빠르고 쉽게 재학습하는 경로다.
- 현재 밸런스의 기본 primary metric은 실제 terminal 진행도다. 같은 configuration과 held-out seed에서 강한 기준 정책 대비 차이, stage별 생존 분포와 하위 분위수를 함께 평가한다.
- 완주 가능한 configuration에서는 full-clear rate를 primary metric으로 선택할 수 있다. 지표·version, 선택 순서, 목표 성능, 최소 효과 크기와 허용 회귀 기준은 실험 전에 고정한다.
- 완주 0회를 AI 실패, 완주 불가능성 증명 또는 최적 플레이 달성의 증거로 해석하지 않는다. 기준 정책보다 강하다는 결과는 비교 상대에 대한 증거이며 이론적 최적성의 증명이 아니다.
- 재학습 효율도 해당 configuration의 사전 목표까지 필요한 비용과 같은 예산의 성능으로 판정한다. 완주를 재학습 구현·검증의 선행 조건으로 두지 않는다.
- AI 성능, 밸런스 설계 목표, 재학습 효율을 각각 평가한다. configuration 간 원시 진행도 차이를 AI 실력 차이로 간주하지 않는다.

## 결과와 남은 작업

목표·평가·재학습 계약을 수정한다. 과거 실험 수치와 artifact는 재작성하지 않는다. 기존 artifact의 `terminal_clear_rate`는 완주율이 아닌 진행도이며 이를 보고서에서 명확히 표기한다.

현재 재학습 코드의 full-clear 우선 checkpoint 선택은 유지된 구현 사실이다. 비교 실험 전에 metric 선택을 spec에 명시하고, 개발 checkpoint 선택과 report에도 같은 계약을 적용하는 구현이 필요하다. 모든 정책의 full-clear가 0인 기존 실험에서는 동률 해소용 진행도로 선택되므로 선택 결과가 자동으로 바뀌었다고 주장하지 않는다.

독립 학습 최소 3회, 잠근 held-out 평가, 같은 seed의 paired 비교, 모든 준비·학습 비용 기록과 provenance 요구사항은 유지한다. 아직 최소 개선 폭 등의 수치 기준이나 새 비교 실험 결과는 확정되지 않았다.
