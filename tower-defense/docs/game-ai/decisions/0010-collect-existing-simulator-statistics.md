# 0010: 현재 범위를 AI 반복 실행과 기존 통계 수집으로 한정한다

- 상태: Accepted
- 결정일: 2026-10-09
- 범위 조정: [0009](0009-balance-appropriate-evaluation.md)의 평가 지표 정의는 유지하며, 강도 개선을 현재 통계 기능 완료의 선행 조건으로 두지 않는다.

## 결정

사용자는 밸런스 조정과 방법론을 향후 콘텐츠 추가·레벨 디자인 단계로 미뤘다. 현재 필요한 기능은 simulator에서 AI로 많은 게임을 실행하고 기존 `all-stats`에서 제공하는 수준의 지표를 수집하는 것이다.

현재 승인 기준은 지정 모델·설정·seed로 게임을 실제 종료까지 실행하고, 기존 통계의 정의를 유지하며 결과와 상세 기록을 저장·조회할 수 있는가다. 인간 플레이 대표성, 최적성 증명, 특정 완주율, 새로운 밸런스 평가 체계는 승인 조건이 아니다.

## 결과

- 현재 PPO/BC checkpoint를 기존 `simulate --all-stats` 및 SQLite 통계 경로에 연결한다.
- 진행도 분포, 피해량, 아이템·유물 등의 선택과 성과 통계를 수집한다.
- 불완전한 실행은 정상 게임 결과와 분리하고, 설정·모델·seed 출처를 보존한다.
- 기존 학습·재학습 구현은 보존한다. 추가 강도 연구, 재학습 효율 비교, 밸런스 자동 조정과 사람 모델은 후속 작업으로 관리한다.
- 자세한 사용법과 지원 범위는 [23](../23-batch-simulation-statistics.md)에 기록한다.
